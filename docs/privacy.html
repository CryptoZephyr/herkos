Privacy

A small site with a small data footprint.

Last updated: August 12, 2026. This page describes the current public Herkos demo.

What we collect

No account is required

The public Herkos site does not ask for a name, email address, password, payment, or uploaded file. It does not include advertising or analytics in the current build.

The site uses browser memory to render the page. Herkos has no account system and no database that stores wallet data.

Network requests

Live readings go to public endpoints

The Mainnet page makes read-only requests to public Flare and XRP Ledger endpoints. The Coston2 page reads the public Coston2 RPC for balances and contract state. Those services may receive normal connection information such as an IP address under their own policies.

If a visitor opens an explorer, faucet, or repository link, that site handles the visit under its own privacy policy.

Wallet use

Connection is optional and user initiated

The Coston2 page requests wallet access only after a visitor presses Connect. If the visitor signs a transaction, the wallet address and confirmed transaction data become public on Coston2. Herkos does not copy that information to a Herkos database.

If a visitor rejects a wallet request, the request stays inside the wallet provider. Herkos receives the rejection needed to show a recoverable message, but does not store it.

Third parties

External services have their own rules

The current Coston2 page uses the public RPC at https://coston2-api.flare.network/ext/C/rpc, Coston2 Explorer, and the official Flare faucet. The Mainnet page may read public Flare and XRP Ledger data. Herkos does not control the privacy practices, availability, or retention policies of these services.

Changes

When this notice changes

If the site adds accounts, analytics, forms, or another data-using feature, this notice should be updated before that feature is released. The date at the top identifies the current version.
