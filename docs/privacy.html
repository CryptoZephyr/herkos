Privacy

A small site with a small data footprint.

Last updated: August 12, 2026. This page describes the current public Herkos demo.

What we collect

No account is required

The public Herkos site does not ask for a name, email address, wallet connection, password, payment, or uploaded file. It does not include advertising or analytics in the current build.

The site uses browser memory to render the page. It does not use a Herkos account or a Herkos database.

Network requests

Live readings go to public endpoints

When live data is available, the browser makes read-only requests to public Flare and XRP Ledger endpoints. Those services may receive normal connection information such as an IP address under their own policies. Herkos does not send a wallet address or transaction request.

If a visitor opens a link to an explorer or repository, that site handles the visit under its own privacy policy.

Third parties

External services have their own rules

The public page links to Flare Explorer and may read public blockchain data from Flare and the XRP Ledger. Herkos does not control the privacy practices, availability, or retention policies of those services.

Changes

When this notice changes

If the site adds accounts, analytics, forms, or another data-using feature, this notice should be updated before that feature is released. The date at the top identifies the current version.
