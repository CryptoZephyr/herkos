Official documentation

A clearer exit signal for FXRP lending.

Herkos measures how much FXRP can leave Flare when lending positions need to exit. It turns that measurement into a conservative price adjustment that Compound-style markets can use.

Overview

What Herkos does

A normal lending oracle can tell a market the current price of FXRP. Herkos adds another question: how much of the asset can realistically leave the system if many positions need to exit at once?

It measures redemption demand, liquid Core Vault funds, and eligible trading depth. Larger exits receive a more conservative haircut. The oracle keeps the existing lending interface, so a market can use the signal without a new pricing flow.

For lenders

A position value that reflects both market price and observed exit conditions.

For integrators

A Compound-compatible price interface with the risk adjustment derived on-chain.

Coston2 test market

Try the oracle with faucet assets

The separate Coston2 test market is a real testnet lending contract. It accepts faucet FTestXRP as collateral and faucet USDT0 as liquidity and debt. You can connect a browser wallet, refresh the oracle, supply liquidity, deposit collateral, borrow, repay, and withdraw.

The market uses a 70% maximum loan-to-value ratio, a 75% liquidation threshold, a 5% liquidation bonus, and no interest accrual. Every confirmed action is a Coston2 transaction with a link to the explorer. Testnet assets have no monetary value.

The Mainnet page remains read-only. Its lending integration is a pinned fork result against an existing deployed market. The Coston2 market is a Herkos deployment for testing, not an external protocol adoption.

Data and freshness

Read each number with its source

The public site separates live readings from the pinned lending-market result. Live readings show the Flare block used for the read. The stress result shows the shared fork block and capture time for every comparison.

  • Live Flare reads change as the network changes.
  • The XRP Ledger read cross-checks Core Vault backing and escrow conditions.
  • The FDC example is a replayed finalized proof, not a new mainnet request.
  • Historical demand describes what users requested. It is not a guaranteed capacity ceiling.

Boundaries

What this project claims

Herkos is a measured research prototype and hackathon integration. The demo does not claim that a live lending market has adopted the oracle or that FXRP is currently insolvent.

The pinned result replays deployed Flare state on a mainnet fork. It is useful evidence for the integration, but it is not a live protocol change.
