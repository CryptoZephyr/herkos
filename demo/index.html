How Herkos works

01

Measure what can leave

Herkos reads the open redemption queue, liquid Core Vault funds, and DEX liquidity that can trade into a stable asset.

02

Price the delay

It turns exit size and observed settlement time into a conservative haircut. Cross-chain evidence can only lower the measured capacity.

03

Use it in lending

It returns the same price method used by Compound-style lending markets. Lending markets can use it without a new interface.

Scope

Where this result applies

Read the technical docs ↗

Forked integration. This lending stress result uses deployed Flare state replayed on a pinned fork. It is an integration result, not a live protocol change.

Replayed proof. The FDC proof is finalized and real. This demo replays an attestation that FAssets already paid for; no new mainnet request was made.

Demand is not capacity. Redemption history shows what users requested. It does not set the maximum the system can settle.

Refreshes cost gas. Reading the measurement is permissionless, but a production deployment still needs an update schedule and incentive.
